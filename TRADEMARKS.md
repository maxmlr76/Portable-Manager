# Name and logo

The MIT license in `LICENSE` covers the source code. It does **not** cover the
"Maxtrix" name or the Maxtrix logo, which remain with the project owner. The logo files are:

- `crates/app/assets/maxtrix.ico`
- `crates/app/assets/tray-32.png`
- `crates/app/ui/assets/maxtrix-icon-chrome-1024.png`

You may keep these files to build and run the unmodified project, and you may
refer to the project by name. If you distribute a modified version or a fork, give it
a different name and replace the logo, so that nobody mistakes it for this project.
